01 / THE BENCHMARK

One question.
A complete set of moments.

Given an audio recording and a language query, return the start and end of every matching interval. TAG-Bench spans word boundaries, acoustic events, meaning, emotion, and recordings up to 20 minutes long.

08

Ways to ask
“when?”

Six short-audio subsets and two long-audio subsets, with both single and repeated targets.

Subsets draw from different sources. Comparisons describe this benchmark; they do not isolate the effect of query type or audio duration.

04 / REPRODUCIBLE EVALUATION

From timestamps
to a complete score.

A small Python package with no runtime dependencies. Normalize responses, align them with annotations, and report overlap, count accuracy, and parsing reliability together.

Union IoU & Recall
Merge overlapping intervals and measure all target occurrences.
gIoU & midpoint MAE
Measure displacement. Report MAE with its evaluated-sample coverage.
Count accuracy & Fail
Keep failures in the denominator. Count missing and extra occurrences.
